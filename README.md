# The Long March

> Music for impossible journeys.

**The Long March** is a living, versioned playlist built around emotional progression rather than genre. It should feel like a civilization at war: gathering, oath, march, clash, siege, triumph, loss, and return.

## Current release

- **v0.3 — Importable Baseline**
- 78 tracks retained from the v0.2 import results because Spotify marked them as found.
- 22 unresolved entries are preserved in `data/unresolved-v0.2.csv` for deliberate replacement or metadata correction.
- This release is a clean baseline, not yet the fully re-curated v0.9 release.

## Core principles

1. Every track must earn its place.
2. Every song should make the next song better.
3. Feeling outranks genre and popularity.
4. The playlist should maintain forward motion and avoid becoming melancholy overall.
5. No more than two songs by the same artist in a ten-track window unless a chapter intentionally demands it.
6. Major vocal and instrumental textures should rotate regularly: throat singing, female vocals, choirs, orchestral scale, and medieval instrumentation.

## Intended listening contexts

Driving, camping, outdoor work, lifting, homelab work, Minecraft, and sustained focus.
