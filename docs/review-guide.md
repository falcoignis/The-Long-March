# Review Guide

Score each candidate from 1–10 in these categories:

- Atmosphere
- March energy
- Vocal power
- Emotional peak
- Transition value
- Replayability

## Review rules

- A famous track receives no automatic advantage.
- Album cuts may beat singles.
- A track can be excellent and still fail the playlist.
- Repeated emotional waves are preferred over one uninterrupted climb.
- Every 10–15 tracks should contain a genuine peak.
- Rejections should include a reason so they can be reconsidered intelligently later.
