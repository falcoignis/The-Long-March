# Philosophy

The Long March is not a Viking playlist. It is a campaign soundtrack built around determination, purpose, tribal power, brotherhood, heroism, triumph, and reflection after battle.

## Emotional target

The listener should feel that an impossible objective lies ahead and that turning back is no longer an option.

## Target balance

- Heroic / anthemic: 40%
- Tribal / ritual: 35%
- Cinematic orchestral: 15%
- Atmospheric: 10%

## Selection test

A track belongs only when it strengthens the journey, not merely because it is individually good.
